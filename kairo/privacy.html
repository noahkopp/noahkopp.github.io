Kairo Privacy Policy

Last updated: November 24, 2026

Kairo is a personal assistant app used only by its developer, for their own Google account.

What Kairo accesses

With the account owner's permission, Kairo reads Gmail messages, creates Gmail drafts and (with explicit confirmation) sends email, and reads and adds Google Calendar events. It uses this data only to answer the owner's own requests, such as summarizing new email or listing upcoming events.

Where data goes

Data is processed on the owner's own computer and in the owner's private GitHub repository (GitHub Actions and GitHub Models) to produce responses for the owner. Kairo does not sell, share, or transfer Google user data to anyone else, does not use it for advertising, and does not use it to train AI models. Kairo's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Sign-in tokens are stored on the owner's computer and as encrypted secrets in the owner's private GitHub repository. Access can be revoked at any time at myaccount.google.com/permissions.
